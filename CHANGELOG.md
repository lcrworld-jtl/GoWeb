# Changelog

All notable changes to GoWeb Browser will be documented in this file.

## [v12] - 2026-05-04

### Added
- Complete core rewrite for stability and performance
- Proper runtime permission handling (camera, storage)
- Full bilingual support (English/Chinese) with language switching
- Robust file download system with cookie forwarding
- Secure SSL error handling with user confirmation dialogs
- File chooser support for web uploads (API 21+)
- Night mode support with automatic detection
- Custom user agent switching
- Ad blocking functionality
- QR code scanner with permission handling
- Offline page saving to app private directory
- Page translation via Google Translate proxy
- View page source functionality
- Find in page with match highlighting
- Multi-tab browsing with independent WebView instances
- Bookmark management with folder support
- Browsing history with time-based grouping
- Download history tracking
- Saved pages for offline reading
- Custom dialog system with green theme
- Smooth animations throughout the app
- Homepage with quick action buttons
- Settings for personalization

### Changed
- UI overhaul with modern card-based design
- Improved navigation and button feedback
- Better error page handling
- Enhanced WebView lifecycle management
- Optimized APK size while maintaining functionality

### Fixed
- Tab pages not showing in list
- URL recognition in search box
- Offline pages not visible
- Storage permission not requested
- Dialogs not displaying properly
- Download double-trigger bug
- Handler memory leaks
- CustomDialog click-through issues
- Language switching inconsistencies

## [v11] - Earlier

- Storage permission handling
- Saved pages directory
